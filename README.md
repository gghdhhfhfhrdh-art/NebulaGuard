# NebulaGuard

NebulaGuard — утилита для поиска читов и подозрительных модификаций на ПК игрока. Программа помогает администраторам серверов и владельцам проектов выявлять нечестную игру и собирать доказательства нарушений.[web:33][web:35][web:36][web:38][web:41]

## Возможности

- Сканирование файлов и папок на наличие известных читов и инжекторов  
- Анализ запущенных процессов и сервисов  
- Проверка следов ранее установленных чит‑клиентов  
- Формирование отчёта для отправки администрации  
- Режим "безопасной проверки" без удаления файлов

## Статус проекта

Проект в активной разработке. Сигнатуры читов и алгоритмы детектов регулярно обновляются.
